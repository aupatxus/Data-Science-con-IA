## Módulo 1
### Fundamentos y herramientas aplicadas a Data
*Este bloque introductorio te proporcionará una base sólida en programación y las herramientas fundamentales para iniciar tu camino en Data Science.*
* Python aplicado al análisis y tratamiento de datos
* Lógica computacional, estructuras de control y funciones
* Colecciones de datos: listas, tuplas, diccionarios
* Programación Orientada a Objetos en Python
* Visual Studio Code y control de versiones con Git/GitHub
* IA aplicada a Data: pair-programming, debugging y aprendizaje asistido

## Módulo 2
### Data Analysis & Visualization
*Este bloque te sumergirá en el corazón de la Inteligencia Artificial, donde aprenderás a construir y evaluar modelos predictivos complejos.*
* Bases de datos relacionales (SQL) y no relacionales (NoSQL)
* Extracción de datos: APIs y Web Scraping
* Manipulación y limpieza de datos con Pandas, NumPy y Regex
* Visualización con Matplotlib, Seaborn, Plotly y Power BI / Tableau
* Estadística descriptiva e inferencial
* Storytelling y comunicación de resultados a stakeholders
* Git, Agile y trabajo colaborativo
* IA aplicada al análisis: limpieza, exploración y generación de insights

## Módulo 3
### Machine Learning Engineering
*Aprendizaje supervisado y no supervisado.*
* Regresión, clasificación, clustering y series temporales (ARIMA)
* Algoritmos: SVM, KNN, árboles de decisión, ensembles, XGBoost
* Feature Engineering y reducción de dimensionalidad (PCA)
* Redes neuronales artificiales y Deep Learning
* Procesamiento de Lenguaje Natural (NLP) y modelos preentrenados
* Keras, TensorFlow y Scikit-learn
* IA aplicada al modelado: experimentación, evaluación y documentación asistida

## Módulo 4
### Deployment y Big Data
*En este último bloque, te centrarás en la puesta en producción de tus modelos y en el manejo de grandes volúmenes de datos.*
* Desarrollo de APIs con Flask
* Contenedores Docker y arquitecturas escalables
* Despliegue en AWS: EC2, RDS y servicios cloud
* MLOps: integración, mantenimiento y monitorización de modelos en producción
* Integración con IAs avanzadas (ChatGPT, modelos preentrenados)
* Big Data y procesamiento con PySpark
* IA aplicada a DevOps y observabilidad
